# MD Drums style guide, v14

The guides of v8 to v13 hold; v14 adds one rule.

## Rules

- **A code comes with its meaning.** Where the Machinedrum's vocabulary is a code (E12, TRX, P-I), the plain word for
  what it is sits under it, small: the code for those who know the machine, the word for those who look for "samples".

## Type

| Use | Size, colour |
|---|---|
| What a family is (browser) | 12 px regular, ink-dim, under the family's code |
