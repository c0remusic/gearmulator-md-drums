# MD Drums style guide, v11

The guides of v8 to v10 hold; v11 changes two rules.

## Rules

- **A page's title stands alone.** No line of explanation after it: the Machinedrum's page names are the vocabulary.
- **Every page has the same anatomy**: title, then over each row of knobs a rule from the first knob's edge to the
  last's. Where the row holds named groups (EFX, ROUTING), each group's name opens its rule and the rule breaks between
  groups; where it does not (SYN, whose parameters change with the machine), the rule runs unnamed over the row. This
  replaces v8's "a line must say something" for these rules: here the rule says "one row", and the user preferred one
  anatomy for the three pages to a rule only where a group has a name.
