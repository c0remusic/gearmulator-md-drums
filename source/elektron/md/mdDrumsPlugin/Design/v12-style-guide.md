# MD Drums style guide, v12

The guides of v8 to v11 hold; v12 adds the browser's behaviour.

## Rules

- **Offer only what sounds.** A machine whose slot is empty is not listed; it returns when it can be filled.
- **Choosing is hearing.** In the browser and with ‹ ›, a machine is loaded and played in one gesture; a switch turns
  the playing off. Keeping and going back are explicit: Garder, Annuler.
- **A preview is built like a page**: name, parameters as the page will show them, screen where the pages put theirs.

## Browser states

| State | Look |
|---|---|
| Machine chosen | 3 px accent bar on its left, text in ink; its name in the preview |
| Machine under the pointer | Text in ink; its name, family and parameters in the title line |
| Garder | 12 px semibold in the accent |
| Annuler | 12 px ink-dim, to ink on hover |
| Écouter en choisissant, on / off | 16 px square filled in the accent / outlined in `track` |
| Unused parameter in the preview | 35 % opacity |
